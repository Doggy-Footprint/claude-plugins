# claude-plugins

```bash
claude plugin marketplace add Doggy-Footprint/claude-plugins
claude plugin install scored-web-search@doggy-footprint
claude plugin install learn-to-tell@doggy-footprint
```

자동 업데이트: `/plugin` → Marketplaces → `doggy-footprint` → Enable auto-update.

learn-to-tell을 claude.ai(웹·모바일)에서 쓰려면 [learn-to-tell README](https://github.com/Doggy-Footprint/learn-to-tell#claudeai-웹모바일-앱)를 참고.
